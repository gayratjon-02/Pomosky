# Languages

Pomosky is offered in English (the source), Uzbek, Russian and Korean.

- **One source of translations:** `internal/i18n/locales/{uz,ru,ko}.json`. The key of every
  text is its English wording; a missing translation shows English. The same files are used
  by the server templates (embedded in the binary) and bundled into the frontend.
- **Templates:** `{{$.T "Text"}}` for plain text, `{{$.H "Text with <strong>markup</strong>"}}`
  for texts with simple markup (only our own locale files can reach it). Use `$`, not `.`, so it
  also works inside `range` and `with`.
- **Frontend:** `t("Text", {name: value})` and `tn("{n} session|{n} sessions", n)` from `core/i18n.ts`.
  Placeholders are written `{name}`. A text that depends on a count lists its plural forms joined
  by `|` (Russian needs three: one, few, many; Uzbek and Korean may list one).
- **Go code:** page titles, descriptions and notices written in controllers are translated by
  `render` (see `controllers/helpers.go`), so add them to the locale files too.
- **Which language:** the `pomosky_lang` cookie (set by the switcher in the header), else the
  browser's `Accept-Language`, else English. The page is rendered in that language and
  `<html lang>` says which; push alerts use the language of the browser that subscribed.
- **Not translated:** the admin page and the development pages (sky lab, mobile preview).
  City names, the brand and the literal word `delete` that confirms an account deletion stay as they are.

`go test ./internal/i18n` fails when a text used in a template, in the frontend or in a controller
has no translation, when a translation is not used any more, or when a translation changes
a `{placeholder}`, a tag or the number of plural forms.

To add a text: write it in English where it is used, add it to the three locale files.
To add a language: add it to `Supported` and `Names` in `internal/i18n/i18n.go`, create its
locale file and import it in `web/src/core/i18n.ts`.
