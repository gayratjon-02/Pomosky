# Pomosky

Pomodoro + sky. Host taymerni boshqaradi, tomoshabinlar havola orqali qo'shilib birga ishlaydi. Xonaning fon osmoni host joylashuvidagi haqiqiy ob-havo va quyosh holatiga qarab jonli o'zgaradi.

- Backend va sahifalar: Go (SSR, MVC)
- Interaktiv qism: oddiy TypeScript modullar
- Ma'lumotlar bazasi: PostgreSQL
- Hosting: Azure VM (Docker Compose, Caddy)

Holat: boshlang'ich tuzilma. To'liq reja: `../pomosky-plan.md` (keyin `docs/` ga ko'chiriladi).
